1. Creating a bibliography and citing sources

This guide shows how to create a small bibliography, cite records in a ConTeXt document, and place the resulting bibliography in the output.

The aim is deliberately practical. By the end of the guide, you should be able to:

  • create a bibliographic record in a .bib file;
  • understand the role of a record category, fields, and a citation key;
  • load bibliographic data into ConTeXt;
  • cite a book or article in the running text;
  • print a bibliography containing the cited records;
  • diagnose the most common errors in a minimal bibliography workflow.

This guide concentrates on the first working bibliography.

Datasets, renderings, selection methods, sorting policies, multiple bibliographies, and the detailed comparison of bibliographic styles are introduced in the later guides.

2. What you need

To follow the examples, you need:

  • a current ConTeXt MkIV or LMTX installation;
  • a text editor;
  • a source file ending in .tex ;
  • a bibliographic file ending in .bib ;
  • UTF-8 encoding for both files.

A bibliography manager such as JabRef can make the creation and maintenance of .bib files easier.

JabRef is only one possible tool. You may use Emacs or any other suitable text editor, provided that the .bib file is saved in UTF-8.

Important. A bibliography manager does not typeset the bibliography.

It helps create and maintain the data. ConTeXt reads those data and decides how citations and bibliography entries are displayed.

3. The basic workflow

A minimal bibliography workflow contains five stages: 

bibliographic record
        |
        v
     .bib file
        |
        v
 ConTeXt dataset
        |
        +----------> citation
        |
        v
 bibliography list

In practical terms:

  1. create one or more bibliographic records;
  2. save them in a .bib file;
  3. load the file with \usebtxdataset ;
  4. cite a record with \cite ;
  5. place the bibliography with \placelistofpublications .

The sections below introduce each stage separately.

4. Creating bibliographic data

4.1. A first book record

A BibTeX record for a book can be written as follows: 

@Book{beiser1987,
  author    = {Beiser, Frederick C.},
  title     = {The Fate of Reason},
  subtitle  = {German Philosophy from Kant to Fichte},
  publisher = {Harvard University Press},
  address   = {Cambridge, Massachusetts},
  year      = {1987},
}

The record begins with: 

@Book

This is the bibliographic category. It tells ConTeXt that the record describes a book.

The text: 

beiser1987

is the record key. It uniquely identifies the record inside the bibliographic dataset.

The remaining elements are fields: 

author
title
subtitle
publisher
address
year

Each field associates a name with a value.

Key distinction.

The record key is used by ConTeXt to retrieve the record. It is not normally printed as part of the citation or bibliography entry.

4.2. A first article record

An article record uses a different category and different fields: 

@Article{ameriks1981,
  author  = {Ameriks, Karl},
  title   = {Kant's Deduction of the Categories},
  journal = {The Monist},
  year    = {1981},
  volume  = {64},
  number  = {4},
  pages   = {451--470},
}

Here:

  • @Article identifies a journal article;
  • journal names the periodical;
  • volume and number identify the issue;
  • pages gives the page range.

The exact set of relevant fields depends on the category and on the active bibliographic specification.

4.3. Categories, fields, and record keys

Common record categories include: 

@Book
@Article
@InCollection
@InProceedings
@PhdThesis
@Misc

Common fields include:

  • author ;
  • editor ;
  • translator ;
  • title ;
  • subtitle ;
  • booktitle ;
  • journal ;
  • publisher ;
  • address ;
  • year ;
  • volume ;
  • number ;
  • pages ;
  • doi ;
  • isbn ;
  • language ;
  • note .

The order of the fields inside a record is not significant.

The record key should:

  • contain no spaces;
  • remain stable once it is used in a document;
  • be unique inside its dataset;
  • be easy to recognise and type.

A common pattern combines an author name and a year: 

beiser1987
ameriks1981
jacobi1785

Other consistent key systems are equally possible.

4.4. Authors, editors, and translators

A single author can be written in natural order: 

author = {Frederick C. Beiser},

or with the family name first: 

author = {Beiser, Frederick C.},

The comma-separated form is useful when the family name contains particles, suffixes, or several words.

Several authors must be separated with the word and: 

author = {Frederick C. Beiser and Karl Ameriks},

Do not separate authors with commas or semicolons.

Editors and translators use their own fields: 

editor     = {Wood, Allen W.},
translator = {Di Giovanni, George},

Common mistake.

A comma separates parts of one personal name. The word and separates different people.

4.5. UTF-8 and clean bibliographic data

ConTeXt works naturally with UTF-8. Accented letters and non-Latin characters can therefore normally be entered directly: 

author = {Friedrich Heinrich Jacobi},
title  = {Über die Lehre des Spinoza},

Bibliographic files should contain publication data rather than elaborate typesetting instructions.

For example, prefer: 

title = {The Fate of Reason},

rather than inserting font commands directly into the title.

Capitalisation, punctuation, italics, quotation marks, and the order of fields should normally be controlled by the bibliographic specification.

4.6. Editing the database with JabRef or a text editor

JabRef provides forms for entering records and can help manage:

  • record categories;
  • field names;
  • citation keys;
  • DOI and ISBN data;
  • duplicate records;
  • groups and keywords.

The resulting file remains an ordinary UTF-8 text file.

A record created in JabRef can therefore be inspected or modified in Emacs, Vim, Visual Studio Code, Notepad++, or another editor.

Practical recommendation.

Use a bibliography manager when maintaining many records, but keep the .bib file readable and portable. This makes the data usable by ConTeXt and by other tools.

5. Creating the bibliographic file

Create a file named: 

references.bib

and save the following records in it: 

@Book{beiser1987,
  author    = {Beiser, Frederick C.},
  title     = {The Fate of Reason},
  subtitle  = {German Philosophy from Kant to Fichte},
  publisher = {Harvard University Press},
  address   = {Cambridge, Massachusetts},
  year      = {1987},
}

@Book{jacobi1785,
  author    = {Jacobi, Friedrich Heinrich},
  title     = {Über die Lehre des Spinoza
               in Briefen an Herrn Moses Mendelssohn},
  publisher = {Gottlieb Löwe},
  address   = {Breslau},
  year      = {1785},
}

@Article{ameriks1981,
  author  = {Ameriks, Karl},
  title   = {Kant's Deduction of the Categories},
  journal = {The Monist},
  year    = {1981},
  volume  = {64},
  number  = {4},
  pages   = {451--470},
}

These records are sufficient for the first complete example.

6. Loading bibliographic data into ConTeXt

Create a second file named: 

bibliography-example.tex

The command: 

\usebtxdataset[default][references.bib]

loads the records from references.bib into a dataset named default.

At this stage, the important point is simple:

  • references.bib is the file containing the data;
  • default is the name under which ConTeXt makes those data 
 available.

The deeper distinction between files and datasets is developed in Guide 2.

Next, load a bibliographic specification: 

\usebtxdefinitions[apa]

This example uses the APA specification because it provides a convenient author–date style for a first demonstration.

Other styles and specifications, including Chicago-style workflows and numerical systems, are discussed in Guide 2.

Do not confuse data and style.

The .bib file contains publication data. The command \usebtxdefinitions[apa] determines how those data are presented.

7. Producing a first citation

A record is cited by its key: 

\cite[authoryear][beiser1987]

The first optional argument selects a citation form. In this example, authoryear requests an author–year citation.

The second argument identifies the record: 

beiser1987

The citation key itself is not the citation text. ConTeXt retrieves the record and constructs the displayed citation from its fields.

For example: 

Beiser gives a detailed account of the philosophical controversies
that followed Kant \cite[authoryear][beiser1987].

A second record can be cited in the same way: 

Jacobi's intervention played a decisive role in the pantheism
controversy \cite[authoryear][jacobi1785].

Several keys can also be cited together: 

These questions have been discussed in both historical and modern
studies \cite[authoryear][beiser1987,ameriks1981].

The exact punctuation and appearance depend on the active specification.

8. Placing the bibliography

The command: 

\placelistofpublications

places a bibliography list at the current position in the document.

A simple document can therefore end with: 

\subject{Bibliography}

\placelistofpublications

The bibliography is constructed from the records used by the document and from the active bibliography settings.

The same data therefore serve two different purposes:

  • \cite produces a citation in the text;
  • \placelistofpublications produces complete entries in a list.

9. A complete two-file example

9.1. The bibliographic file

Save the following as references.bib: 

@Book{beiser1987,
  author    = {Beiser, Frederick C.},
  title     = {The Fate of Reason},
  subtitle  = {German Philosophy from Kant to Fichte},
  publisher = {Harvard University Press},
  address   = {Cambridge, Massachusetts},
  year      = {1987},
}

@Book{jacobi1785,
  author    = {Jacobi, Friedrich Heinrich},
  title     = {Über die Lehre des Spinoza
               in Briefen an Herrn Moses Mendelssohn},
  publisher = {Gottlieb Löwe},
  address   = {Breslau},
  year      = {1785},
}

@Article{ameriks1981,
  author  = {Ameriks, Karl},
  title   = {Kant's Deduction of the Categories},
  journal = {The Monist},
  year    = {1981},
  volume  = {64},
  number  = {4},
  pages   = {451--470},
}

9.2. The ConTeXt source

Save the following as bibliography-example.tex: 

\mainlanguage[en]

\setupbodyfont
  [libertinus,10pt]

\usebtxdataset
  [default]
  [references.bib]

\usebtxdefinitions
  [apa]

\starttext

\startchapter
  [title={Reason, faith, and criticism}]

Beiser presents the controversy surrounding the fate of reason
after Kant \cite[authoryear][beiser1987].

Jacobi's intervention made the question of Spinozism central to
German philosophy \cite[authoryear][jacobi1785].

A modern discussion of Kant's categories can be found in
Ameriks \cite[authoryear][ameriks1981].

\stopchapter

\startchapter
  [title={Bibliography}]

\placelistofpublications

\stopchapter

\stoptext

9.3. Compiling the example

Place both files in the same directory and run: 

context bibliography-example.tex

On Windows, use Command Prompt or PowerShell. On Linux or macOS, use a shell such as Bash.

ConTeXt may require more than one processing pass while references and lists stabilise.

Expected result.

The document contains three author–year citations and a bibliography with the three corresponding entries.

10. How the example works

The example performs four main operations.

10.1. Loading the data 

\usebtxdataset
  [default]
  [references.bib]

This loads the bibliographic records from the file into the dataset named default.

10.2. Loading the specification 

\usebtxdefinitions
  [apa]

This loads the APA bibliography definitions.

10.3. Citing a record 

\cite[authoryear][beiser1987]

This retrieves the record whose key is beiser1987 and formats it as an author–year citation.

10.4. Placing the list 

\placelistofpublications

This places the bibliography at the current position.

The separation of responsibilities is already visible:

Element Role
references.bib Stores the bibliographic records.
\usebtxdataset Loads the records into ConTeXt.
\usebtxdefinitions Selects the general formatting rules.
\cite Produces a citation.
\placelistofpublications Produces the bibliography list.

11. A self-contained example using a buffer

For a minimal working example, it is often convenient to keep the bibliographic data and the ConTeXt source in one file.

The records can be stored in a named buffer: 

\startbuffer[biblio]

@Book{beiser1987,
  author    = {Beiser, Frederick C.},
  title     = {The Fate of Reason},
  subtitle  = {German Philosophy from Kant to Fichte},
  publisher = {Harvard University Press},
  address   = {Cambridge, Massachusetts},
  year      = {1987},
}

@Book{jacobi1785,
  author    = {Jacobi, Friedrich Heinrich},
  title     = {Über die Lehre des Spinoza
               in Briefen an Herrn Moses Mendelssohn},
  publisher = {Gottlieb Löwe},
  address   = {Breslau},
  year      = {1785},
}

\stopbuffer

\usebtxdataset
  [default]
  [biblio.buffer]

\usebtxdefinitions
  [apa]

\starttext

Beiser discusses the fate of reason after Kant
\cite[authoryear][beiser1987].

Jacobi's intervention transformed the debate
\cite[authoryear][jacobi1785].

\subject{Bibliography}

\placelistofpublications

\stoptext

The expression: 

biblio.buffer

tells ConTeXt to use the contents of the buffer named biblio as bibliographic input.

When to use a buffer.

A buffer is particularly useful for wiki examples, bug reports, and tests because the entire example can be copied and compiled as a single file.

For a large project, a separate .bib file is usually easier to maintain.

12. Common problems

12.1. The citation remains unresolved

An unresolved citation may display the key or an internal-looking reference instead of the expected author and year.

Check:

  • whether the key is spelled exactly as in the .bib file;
  • whether the bibliographic file has been loaded;
  • whether the correct dataset is being used;
  • whether the document has been compiled again.

For example, these two keys are different: 

beiser1987
Beiser1987

Key spelling and case should be treated consistently.

12.2. The bibliographic file is not found

The command: 

\usebtxdataset[default][references.bib]

expects references.bib to be found from the directory in which the document is compiled.

For the first example, keep both files in the same directory.

If the file is stored in a subdirectory, include the relative path: 

\usebtxdataset[default][bib/references.bib]

12.3. The file is not saved as UTF-8

Incorrect encoding may produce malformed accented characters or parsing errors.

Verify that both the .tex and .bib files are saved as UTF-8.

This is especially important for names and titles containing characters such as: 

Über
Voß
Mendelssohn

12.4. Several authors are separated incorrectly

Incorrect: 

author = {Frederick C. Beiser, Karl Ameriks},

Correct: 

author = {Frederick C. Beiser and Karl Ameriks},

The word and separates authors.

12.5. The key contains spaces

Avoid: 

@Book{Beiser 1987,

Prefer: 

@Book{beiser1987,

12.6. A record is loaded but does not appear

A record may exist in the dataset but not appear in the bibliography because it has not been cited or selected.

In this introductory guide, the simplest test is to cite the record explicitly: 

\cite[authoryear][beiser1987]

The precise relationship between cited records, all dataset records, local selection, and global selection is explained in Guide 2.

12.7. The record category is unsuitable

A record can be syntactically valid but poorly formatted if its category does not match the publication it describes.

For example:

  • use @Book for a monograph;
  • use @Article for a journal article;
  • use @InCollection for a chapter in an edited volume.

When an entry looks incomplete or strange, check both its category and its fields.

Successful loading does not guarantee correct formatting.

ConTeXt may read a record successfully even when the chosen category or field structure is unsuitable for the active bibliography specification.

13. What belongs in the bibliographic data

A good bibliographic file contains stable factual information about publications.

It should normally contain:

  • names;
  • titles and subtitles;
  • dates;
  • publication places;
  • publishers;
  • volume and issue data;
  • page ranges;
  • identifiers such as DOI and ISBN.

It should not normally contain:

  • document-specific punctuation;
  • font changes added only for one output style;
  • manually constructed citation strings;
  • layout instructions tied to one document.

The principle is: 

data in the .bib file
presentation in ConTeXt

This separation makes it possible to reuse the same records with APA, Chicago, numerical, or project-specific conventions.

14. What this guide has established

This guide has introduced the first complete bibliography workflow in ConTeXt.

You have seen that:

  • a bibliographic record has a category, a key, and fields;
  • a .bib file stores structured publication data;
  • JabRef, Emacs, or another UTF-8 editor can be used to maintain those data;
  • \usebtxdataset loads the records into ConTeXt;
  • \usebtxdefinitions loads a bibliographic specification;
  • \cite retrieves and formats an individual record;
  • \placelistofpublications places a bibliography list;
  • a buffer can make a minimal example self-contained;
  • data and presentation should remain separate.

The next guide explains how datasets, bibliographic specifications, renderings, selection methods, and sorting rules work together.
