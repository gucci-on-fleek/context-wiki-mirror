Summary

The command \setnotetext is used to define a (foot)note without marker.

Settings

\setnotetext[...][...,...]{...}
[...] name
[...,...] reference
{...} text

Settings assignment

\setnotetext[...][...=...,...]
[...] name
title text
bookmark text
list text
reference reference
