Summary

The command \usebodyfont[fontspec] performs some font initialization.

Settings

\usebodyfont[...,...]
[...,...] inherits from \setupbodyfont

Description

The command 
\usebodyfont[fontspec]
does either 
\setupbodyfont[fontspec]

if there is no font defined yet, otherwise it does 

\switchtobodyfont[fontspec]%
\fullrestoreglobalbodyfont

The above summary is taken from the definition of this macro found in .../tex/context/base/mkxl/font-ini.mklx in October 2026. Admittedly, this description is not very helpful, but it may nonetheless be of some use to some readers.

People who know more are encouraged to fill out this wiki page.

Example 1 

\usebodyfont[schola]
