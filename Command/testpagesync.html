Summary

The command \testpagesync inserts a page break if there’s less than the specified number of lines or vertical space on the page.

Settings

\testpagesync[...][...]
[...] number
[...] dimension

Description

This is an alternative to \testpage that works a bit differently and maybe more reliable in some cases.
