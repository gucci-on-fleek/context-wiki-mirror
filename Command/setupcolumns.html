Summary

The command \setupcolumns is used to setup the “simple” (AKA “mixed”) version of multi-column layout.

Settings

\setupcolumns[...=...,...]
...=...,... inherits from \setupmixedcolumns

Description

Consider using paragraphs (\defineparagraphs), column sets (\setupcolumnset), or page columns (\setuppagecolumns) instead of ‘simple’ columns.
