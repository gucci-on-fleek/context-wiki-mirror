\showreferences

The command \showreferences enables visual debugging of ConTeXt cross-references. It displays the names of reference targets and the names of the reference invocations that point to them.

Purpose.

Use \showreferences while checking or debugging a document. The diagnostic labels are not intended for the final typeset document.

Example 

\setupinteraction
  [state=start]

\showreferences

\starttext

\startsection
  [title={First section},
   reference={sec:first}]

This is the reference target.

\stopsection

See \in{section}[sec:first]
on \at{page}[sec:first].

\stoptext

In this example, the diagnostic display shows the target name 

sec:first

near the place where the reference is defined, and 

|sec:first

near each place where the reference is invoked.

Thus: 

reference={sec:first}
        |
        v
   destination
     sec:first


\in{section}[sec:first]
        |
        v
 reference invocation
     |sec:first

Equivalent trackers

In current LuaMetaTeX, \showreferences enables the two textual reference-debugging trackers together: 

\enabletrackers
  [nodes.references.show,
   nodes.destinations.show]

They can also be enabled separately: 

\enabletrackers[nodes.destinations.show]

shows destination names, while 

\enabletrackers[nodes.references.show]

shows reference invocations.

Note.

The diagnostic labels may overlap ordinary text. This is normal for a debugging facility and does not indicate a problem with the reference mechanism itself.
